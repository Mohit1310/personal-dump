Decisions and limits

Deliberate constraints keep the system inspectable.

Migrations and writes

  • pgvector base schema plus a metadata migration with legacy backfill.
  • Metadata stays on Dump; no tag table or service layer.
  • Prepare derived content before transactional ingestion/re-index writes.

Retrieval rules

  • Type/tag/source apply with AND before ranking.
  • RRF scores 1 / (60 + rank); stable ties remain inspectable.
  • One significant token gates evidence; duplicates at 80% overlap drop; 12,000 characters cap whole chunks.

Still deferred

  • No production embedding or answer-quality benchmark.
  • No universal relevance threshold, reranker, keyword-only fallback, or version history.
  • #2, #3, #5, and roadmap points 4–6 remain outside this ticket.
